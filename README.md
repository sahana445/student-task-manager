# Student Task Manager

A full-stack web application for managing student tasks efficiently.

## Features

- Add new tasks
- View tasks
- Update task status
- Delete tasks
- Store task data using MongoDB

## Technologies Used

- HTML
- CSS
- JavaScript
- React.js
- Node.js
- Express.js
- MongoDB
